Prompt Pilot

Voice-to-prompt for ChatGPT.

Gemini refinement

Chat context (optional)

On capable computers, the optional chat-context checkbox uses Groq to condense the current conversation before Gemini refines your new prompt. The full conversation is discarded after the operation.

Microphone

Prompt Pilot keeps microphone audio on this device when local transcription is selected.

Transcription

Automatic mode uses local Whisper on capable computers and a lower-bitrate recording with Gemini Transcribe when local processing is not practical.

Local mode sends only transcript text to Gemini for refinement. Cloud mode temporarily sends the recording to Gemini Transcribe, then sends the transcript text to Gemini Flash-Lite. If you explicitly enable chat context on a capable local computer, the current conversation is sent to Groq for condensation and only the compact brief is sent to Gemini. Prompt Pilot does not save recordings, chat exports, transcript history, or analytics.
